03 / Forms

Ввод с предсказуемой валидацией

Label остаётся видимым, help и error занимают одно место в потоке, а invalid-состояние всегда содержит объяснение.

Input · Textarea · Select · Searchfield family
  • Input — Label · Control · Help/Error; 40/44/52; text/number/readonly/disabled/invalid; один факт в поле; label + describedby.
  • Textarea — Label · Control · Counter/Help; min 104 px; default/readonly/disabled/invalid; для многострочного контекста; resize vertical.
  • Select — Label · Trigger · Native list; 40/44/52; default/disabled/invalid; до 15 стабильных вариантов; нативная клавиатура.
  • Search — Label · SearchControl · ResultsStatus; 40/44/52; empty/filled/loading/no-results; задержка запросов; объявлять число результатов через live-region.
Checkbox · Radio · Switchchoice
  • Checkbox — Input · Label · optional Help; 44 target; checked/unchecked/mixed/disabled/invalid; независимый выбор; native input.
  • Radio — Group · Items · Help; 44 target; selected/default/disabled; один вариант из 2–7; fieldset/legend в формах.
  • Switch — Control · Label · State; 44 target; on/off/disabled; немедленное изменение настройки; role=switch и явная подпись.

05 / Feedback + overlays

Сообщения не теряют контекст

Alert живёт в потоке, Inline Message рядом с причиной, Toast подтверждает завершённое действие. Тень используется только у overlays.

Alert · Toast · Inline Messagefeedback

Расчёт обновлён после изменения радиуса L2.

Ниже принятого порога 85%.

  • Alert — Sign · Title · Message · Action; info/success/warning/error; блокирующий контекст; role=alert только для срочного.
  • Toast — Sign · Message · optional Action; до 6 c; success/info/error; подтверждение фонового действия; polite live-region и не единственный канал ошибки.
  • Inline Message — Sign · Text · Action; compact; info/warning/error; рядом с источником; не перекрывает контент.

  • Tooltip — Anchor · Bubble; max 240 px; text only; объясняет краткое действие; hover + focus, не содержит интерактив.
  • Dropdown Menu — Trigger · Menu · Items · shortcuts; overlay; default/hover/disabled/danger; вторичные команды; aria-haspopup, стрелки, Escape.

Modal · Drawerblocking / contextual

Modal подтверждает ограниченную задачу. Drawer сохраняет контекст GIS и подходит для расширенного инспектора.

  • Modal — Backdrop · Dialog · Header · Body · Footer; 480–640 px; default/danger/loading; короткая блокирующая задача; focus trap, Escape, restore focus, aria-modal.
  • Drawer — Backdrop · Panel · Header · Body · Footer; 360–480 px; right/full at 768; подробный контекст без ухода; те же требования к фокусу и закрытию.

10 / Product Patterns

Одна модель экрана, двенадцать точных состояний.

GIS Workspace не меняет анатомию между состояниями: ProjectTree, MapCanvas, ContextBar и ObjectInspector сохраняют места, а loading, selection, validation, save и recovery изменяют только доступность, сообщения и фокус.
