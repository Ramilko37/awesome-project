Fortis Design Language / Exploration 01

Спокойная система для сложных решений.

Fortis превращает геопространственные, технические и финансовые данные в доказуемый план. Интерфейс не симулирует угрозу — он помогает видеть зависимости, обосновывать бюджет и контролировать изменения.

01 / EvidenceДоказательность

Каждое число имеет контекст, единицу, период и источник.

02 / CalmСпокойствие

Цвет сообщает состояние. Иерархию создают типографика и интервалы.

03 / DensityРабочая плотность

Больше данных без тесноты: 8px-сетка, компактные строки, ясные группы.

04 / ContinuityНепрерывность

Один язык для GIS, расчётов, отчётов, входа и настроек.

07 / Decision log

Что становится каноном — и что остаётся в прошлом

Exploration 01 предлагает не новый слой поверх текущего UI, а правила для его последовательной консолидации.

Принять как канон8 решений
  • ✓
    Единые semantic tokens

    Canvas, surface, text, border, action и state-роли для всех модулей.

  • ✓
    IBM Plex Sans + Mono

    Один UI-стек и отдельный data-стек с табличными цифрами.

  • ✓
    Светлые панели, локально тёмная карта

    Dark canvas ограничен картой; инспекторы и финансы остаются светлыми.

  • ✓
    8px baseline + три density mode

    Default для общей работы, compact для GIS/таблиц, comfortable для touch.

  • ✓
    Шесть доменных компонентов

    Эшелон, актив, инспектор, бюджет, покрытие, версия получают устойчивую анатомию.

  • ✓
    Состояние = цвет + текст + знак

    Предупреждения и статусы доступны без зависимости от цвета.

Отклонить при консолидации7 конфликтов
  • ×
    Параллельные global и GIS tokens

    Оставить единый semantic layer; map/data roles — его специализированное расширение.

  • ×
    Визуальные дефолты библиотек

    Radix, shadcn и Ant могут быть primitives, но не источниками внешнего вида.

  • ×
    Несогласованные шрифтовые наборы

    Не смешивать системный, Inter и случайные monospace в разных модулях.

  • ×
    Тень как основной разделитель

    В рабочем UI использовать линии и пространство; тень только у overlay.

  • ×
    Крупные карточки для простых значений

    Плотность должна соответствовать аналитической задаче, не SaaS-шаблону.

  • ×
    Military/game visual language

    Никаких HUD, прицелов, камуфляжа и тревожного красного фона.
